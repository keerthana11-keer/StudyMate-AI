# StudyMate AI 📚

An AI-inspired study planner that helps students organize schedules, track tasks, and improve productivity.

## Features

- Create study plans
- Organize subjects
- Track learning goals
- Simple student-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download the project
2. Open index.html in a browser
